# Insights — Start Here

This is the heart of the second brain. One note per insight. This is where I catch the realizations I keep losing — the "oh, so THAT's why I'm like this" moments.

## The 3 rules (keep it simple, or it won't survive)
1. **One insight per note.** Short beats long.
2. **My own words.** If I can't paraphrase it, I don't understand it yet.
3. **Link it.** Every insight links to at least one other note, or it's a graveyard note I'll never see again.

## What an insight note looks like
Open any `[[Insight: ...]]` note to see the template in action.

## The thread
This folder's real power is the links between notes over time. Read them in order and you can see my own trail — the version of me I can actually look at, even when the fog blurs the present.
