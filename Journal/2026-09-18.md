## What we did today (in order)

1. **Title-bar drag bug fixed.** Corner-resize had been bound to the whole window
   (`attachResize(w, win, "se")`), so dragging the title bar also resized.
   Now `attachResize($(".resize", w), win, "se")` with separate `.resize-r` (right)
   and `.resize-b` (bottom) handles, `setPointerCapture` for smooth drag, and
   `.resize-r { top: 40px }` so it no longer overlaps the title bar.
   (`game/web/static/desktop.js`, `style.css`)

2. **Desktop made honest.** The four app icons are now **real `.desktop` launcher
   files in `~/Desktop`**, copied from **real program files in `/usr/bin`**
   (`terminal`, `files`, `mail`, `notes`) and `/usr/share/applications`. So
   `ls Desktop` and the GUI show the same thing — he had caught the empty-`Desktop`
   inconsistency. (`game/engine/platforms.py`: `PROGRAMS`, `PROGRAM_ICONS`,
   `_program_stub`, `_desktop_entry`; `world.make_player_machine` seeds `~/Desktop`
   and sets `m.gui = True`; `server.py`: `/api/desktop`, `/api/apps`.)

3. **Programs launch from the terminal.** Typing `terminal`, `/usr/bin/files`,
   `gtk-launch terminal`, `dex Desktop/terminal.desktop`, or
   `xdg-open Desktop/notes.desktop` opens the same window as double-clicking the
   icon. Signal `__LAUNCH__:<prog>`, like the existing `__SSH_OK__`.

4. **Launch is Linux-real.** Only a local session on a graphical box has
   `DISPLAY=:0` and can open a window; over SSH to a headless host it fails with
   `Gtk-WARNING **: cannot open display:`. Execute bit enforced
   (`./Desktop/terminal.desktop` → `Permission denied`; `./nope` → `No such file or
   directory`). Fixed the `_is_executable` index bug (2,5,8 not 0,3,6).

5. **Terminal flows top-down like a real terminal.** Removed the pinned bottom bar;
   output and prompt share one scroll region, prompt sits inline after the last
   output (first line when empty, bottom once full).

6. **Terminal made fish-real (the big one).** The key discovery: his Super+T runs
   `kitty`, but his **shell is fish** (`$SHELL=/bin/fish`, via
   `~/.config/kitty/kitty.conf` + `~/.config/fish/config.fish` → cachyos config).
   kitty only forwards keys; the completion he likes is fish's *autosuggestion*.
   So we implemented fish's observable line-editor behaviour, keeping the look:
   - inline **muted-gray autosuggestion** (history first: typing `l` offers `s`
     from a past `ls`; then completions),
   - `→` / `End` / `Ctrl+E` / `Ctrl+F` accept it whole, `Alt+→` accepts first word,
   - fish-style Up/Down **history search** (case-insensitive unless you typed an
     uppercase letter; duplicates removed),
   - Tab completion (commands + paths via `/api/complete`),
   - `Ctrl+C` copy, `Ctrl+V` paste, `Ctrl+Z` interrupt, `Ctrl+L` clear,
   - `Shift+Backspace` clears the line, `Ctrl+A/E/B/F`, `Ctrl+U/K`,
     `Ctrl+W` deletes one path component.
   - Look unchanged: only a muted hint, and the input auto-sizes to its text.
   - Fixed the "l s" gap (flex `gap: 6px` was sitting between input and hint).
   - Fixed argument suggestions: `cd ` now offers the current directory's entries
     (completions first), not the last `cd` from history — history only wins for
     the command word.

7. **Real `cd` semantics fixed** (all were wrong at the engine level):
   - `cd ..` at `/` now stays at `/` (root's parent is itself) — it was erroring.
   - bare `cd` goes home (it went to `/`).
   - `~`, `~/path`, `~user` expand (also in redirects).
   - `cd -` switches to the previous directory (`OLDPWD`).
   (`game/engine/fs.py` `Dir.get("..")` clamp; `interp.py` `cmd_cd`,
   `_expand_tilde`.)

8. **Command/file realism audit** (his ask: "whois is in bin… probably from Grey
   Hack, fix any others"). Findings:
   - **`whois` is real** (Debian/Ubuntu `whois` package) — kept; corrected him.
   - Removed the genuinely non-Linux, Grey-Hack-style commands:
     **`ftpls`**, **`ftpget`** (invented) and **`back`** (game navigation; `exit`
     already did the same).
   - FTP now runs through **real tools**: `lftp -e 'ls; quit' host`,
     `lftp -e 'get path' host`, `curl ftp://host/` (list) / `curl ftp://host/path`
     (print), `wget ftp://host/path` (download). Tested green against `server1`.
   - Everything else in the registry and in `/usr/bin`+`/usr/sbin` checked out real;
     the libs are real too (no fake `libftp.so`/`libhttp.so`).
   - 55 commands now (was 57: −3 +1).

## Decisions
- Implement **fish**'s observable behaviour (not "kitty behaviour" — kitty is just
  the emulator), keep the existing look, defer the rare features.
- **Real tools only** in the game: remove invented commands, map capability onto
  the genuine Linux tool.
- Intrusion design stays **misconfiguration-based** (not version→magic-exploit);
  exploits deferred.
